# Clube da Pelada — app Android

Downloads do app Android do Clube da Pelada (dia de jogo offline). Este repositório guarda só os
arquivos de instalação; o código fica em outro repositório.

**Baixar a versão mais nova:**
https://github.com/gustavopsan/clube-da-pelada-android/releases/latest/download/clube-da-pelada.apk

Ao instalar, permita que o navegador instale apps de fontes desconhecidas quando o Android pedir.
